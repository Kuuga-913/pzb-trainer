影之刃零 修改器（复刻版）
========================================

【怎么用】
1. 先启动游戏（影之刃零 / Phantom Blade Zero），进入存档、能自由行动。
2. 双击本目录下的 PBZTrainer.exe（自带运行时，免安装）。
   · 启动后自动找到 PBZ.exe、注入 PBZBridge.dll、完成握手，并自动解除
     「高级功能」限制（只改游戏进程内存，不动任何文件）。
   · 右上角变成「● 游戏已就绪」即可使用。
   · 按住标题栏可拖动窗口；右上角「置顶 / — / ✕」。
   · 需要直达某页时可用：PBZTrainer.exe --page add|inv|spawn|map|completion|minimap|esp

【界面结构】
左侧是分组导航，右侧是当前分类的功能卡片：
  功能：战斗与生存（16） / 杀气与绝技（9） / 速度与冷却（6） / 破防与处决（7） /
        异常与持续伤害（16） / 格挡与鬼步（6） / 资源与消耗（4） / 飞行与穿墙（5） /
        六十六天模式（4） / 地图与收集（3）
  物品：添加物品 / 背包管理
  世界：生成怪物 / 探索与地图 / 小地图 / 透视
  更多：自定义任务 / 成就 / 外观解锁 / 角色模型 / 技能释放 / 技能连段 / BOSS 招式 / 资源设置 / 武器状态 / 角色属性
  自动化：一键全收集
76 项功能开关全部按类别分散在上面 10 个分类里（19 个开关型 / 48 个数值型 / 9 个执行型），
没有单独的「基础/高级」栏目；再算上 14 个工具页，可操作条目共 3000 余条。
顶部搜索框（Ctrl + F）可在当前分类内按名称 / 说明 / 代号过滤。

【各页说明】
· 战斗与生存：无敌、无限生命、满血应用、低血量自动回满、伤害倍率、秒杀、抗硬直、
  清除负面积累、异常免疫、药品、记忆之花、意识尘埃、坠落免疫等。
· 杀气与绝技：无限杀气、杀气恢复、消耗减免、精纯杀气、影之武装资源。
· 速度与冷却：移动 / 攻击 / 游戏 / 敌人速度、技能冷却、武装切换冷却。
· 破防与处决：快速破防、敌方杀气、破防持续、处决阈值、玩家不被破防。
· 异常与持续伤害：出血 / 灼烧 / 中毒 / 冰冻 / 感电 / 血爆的积累、增幅、时长与概率。
· 格挡与鬼步：完美格挡窗口、招架判定、自动格挡 / 闪避、闪避无敌窗口、自动 QTE。
· 资源与消耗：药剂使用不减、补满药剂、消耗品不减、养成货币倍率。
· 飞行与穿墙：飞天、飞行速度、穿墙移动、安全返回、高度调整。
· 六十六天模式：死亡不扣次数、周目、难度、剩余次数。
· 地图与收集：区域铃铛、全域地图解锁、记忆之花补齐（会写入存档进度）。
· 添加物品：881 项目录，显示已持有数量，选中后按数量添加（1~9999）。
· 背包管理：当前背包 551 项，可改持有数量或删除整条记录（删除不可撤销）。
· 生成怪物：177 种敌人，可设数量 1~10、距离、敌/友军；会显示原生生成状态。
  · 「首领」分类会提示：剧情首领带阶段机制，血量见底后可能不再下降（需要过场/阶段推进）。
  · 右侧有「开启助战预设」：一键打开 伤害倍率 / 秒杀 / 快速破防 / 玩家不被破防 /
    自动完美格挡 / 自动 QTE，打 BOSS 更稳。
  · 还打不动就用「记录当前位置 / 传回记录点」脱战，离开区域后生成的怪会随场景卸载。
· 探索与地图：179 个已解锁地点，选中「前往」直接传送；也可记录当前位置再传回。
· 自定义任务：读取全部任务（80 项）并显示状态，可「标记完成」或「重置任务」；会改变剧情进度。
· 成就：66 项成就，可点亮或取消。
· 外观解锁：9 套服装外观，解锁后到游戏内外观界面切换。
· 角色模型：429 个模型可替换（首领 / NPC / 剧情人物），用完点「还原默认」。
· 技能释放：1500+ 条攻击技能，选中后直接释放一次；被动与配对处决不可单独释放。
· BOSS 招式：播放首领招式，需要锁定首领时才有目录。
· 资源设置：107 项养成资源（铸造金属 / 琥珀 / 货币等），输入数量后点「设置数量」。
· 技能连段：左侧挑招式加入右侧队列（最多 30 步），设好间隔（默认 800ms）点「执行连段」，可随时停止。
· 武器状态：当前武器的能力参数（如每秒伤害加成），改完断开连接会自动还原。
· 角色属性：223 项属性（等级 / 生命 / 伤害与抗性 / 破防 / 移动等），填绝对值写入，改前先记原值。
· 一键全收集：九类收集 / 所有任务 / BOSS 战绩 / 所有地图探索。
  · 执行前会弹窗二次确认；执行中显示「已检查 x/y · 补齐 a · 仅记录 r · 未完成 f」。
  · 结束后会再弹一个结果窗：列出本次补齐了哪些、仅更新了哪些记录、哪些没完成及原因。
  · 随时可点「停止」，已完成部分保留；再点一次会从中间继续。
· 小地图：开启后在游戏画面右上角浮出一张雷达式小地图——中心是你（红箭头为朝向），
  周围是铃铛（金色）、收集点（青色）、挑战（紫色）与敌人（红色，贴边表示在范围外）。
  打开「点击标记可传送」后可直接在小地图上点铃铛传送。切页签不会关掉它。
· 透视：勾选类型（敌人/首领/NPC/宝箱/可拾取/可交互/血量/名称/方框…），开启后在游戏
  画面上直接画框和「名称 + 距离」标签，左上角常驻「ESP · N 个目标」水印。
  每 150ms 取一次目标、画面按帧插值跟随，移动时标签是平滑滑过去的，不会一跳一跳。
  同样切页签不会关掉，需要在上方开关关闭；修改器窗口在前台时悬浮层会自动隐藏。

【快捷键】
· 功能卡片上的「设置快捷键」可为任意功能绑定全局热键（游戏在前台也生效）。
· F1 隐藏 / 显示修改器窗口；Ctrl+F 跳到搜索框。

【数据与存档】
· 开关与数值自动保存：%LOCALAPPDATA%\影之刃零修改器\trainer_state.json
  （字段与原版一致：SelectedPage / AutoSave / OnlyWhenTargetOrPanelForeground /
    PanelToggleHotkey / Features{Enabled,Value,Hotkey}）
· 添加物品、改数量、删除、全收集都会真实写入存档，关掉修改器不会撤销，请先备份。

【常见问题】
· 「请先启动游戏」：游戏没开或还没读到进程，开游戏后自动重连（每 6 秒重试）。
· 「游戏接口尚未就绪」：游戏刚启动，等几秒再点「重新连接」。
· 「游戏仍加载着旧组件…」：游戏里已有旧组件，完全退出游戏再重开即可。
· 小地图/透视开启失败并提示「正在读取游戏目录」：游戏还在加载，等几秒再开。
· 透视显示「视野内暂无目标」：当前画面里没有符合勾选类型的目标（把类型全勾上试试）。

【卸载】
删除本目录，再删除 %LOCALAPPDATA%\影之刃零修改器 即可；不写注册表、不留服务。

【复刻依据（技术备注）】
· 功能清单取自原版模块内嵌资源 PBZFeatures.json（76 条）与 PBZCatalog.json
  （items 790 / enemies 177 / achievements 66 / quests 80 / collections 630 / resources 99）。
· 协议：命名管道 \\.\pipe\ChuwuPBZ_v1_<游戏PID>，帧 = 4 字节小端长度 + UTF-8 JSON；
  每个请求自动附加 requestId / session / clientPid。
  指令：hello、capabilities、feature、collection_step、catalog{type}、grant_items、
  inventory_change、spawn/spawn_status、revive_enemy、position、teleport、
  collection_locate、completion.plan/begin/step/cancel、minimap.configure/frame/
  travel_target、esp.configure/frame/status 等（job / value 等字段须按原类型传，数字就是数字）。
