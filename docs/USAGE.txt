影之刃零 修改器 v1.11.16
========================================

【怎么用】
1. 先启动游戏（影之刃零 / Phantom Blade Zero），进入存档、能自由行动。
2. 双击 PBZTrainer.exe。会弹一次 UAC，点「是」。
   · 程序默认以管理员权限启动——这样游戏无论用普通权限还是管理员权限运行，都能连上。
   · 启动后自动找到 PBZ.exe、连接游戏、解除功能限制（只改进程内存，不动任何文件）。
3. 右上角变成「● 游戏已就绪」即可使用；显示「请先启动游戏」时会每 6 秒自动重连。
   · 拖动标题栏可移动窗口；右上角「置顶 / — / ✕」。
   · 直达某页：PBZTrainer.exe --page add|inv|spawn|map|quest|completion|minimap|esp|hotkeys|diagnostics

【界面结构】
左侧是分组导航（点分组标题可展开/收起），右侧是当前页内容：
  功能：战斗与生存（16） / 杀气与绝技（9） / 速度与冷却（6） / 破防与处决（7） /
        异常与持续伤害（16） / 格挡与鬼步（6） / 资源与消耗（4） / 飞行与穿墙（5） /
        六十六天模式（4） / 地图与收集（3）
  物品：添加物品 / 背包管理
  世界：生成怪物 / 探索与地图 / 小地图 / 透视
  更多：自定义任务 / 成就 / 外观解锁 / 角色模型 / 技能释放 / 技能连段 / BOSS 招式 /
        资源设置 / 角色属性 / 快捷键 / 连接诊断
  自动化：一键全收集
76 项功能开关全部按类别分散在这 10 个分类里（19 个开关型 / 48 个数值型 / 9 个执行型），
没有单独的「基础/高级」栏目；再算上 14 个工具页，可操作条目共 3000 余条。
功能页顶部有搜索框（Ctrl + F），按名称 / 说明 / 代号过滤。

【卡片状态怎么读】
· 「已关闭」：开关没开。
· 「已开启」：游戏侧确认已生效。
· 「已开启 · 未生效」（橙色）：开关开了，游戏侧也回报"已应用"，但实际没起作用——
  多半是当前游戏版本没适配。鼠标悬停能看到具体原因。
· 红字（如「当前版本未生效」）：同样表示该功能在当前版本不可用。

    开启后卡片显示「已开启 · 未生效」：
      药剂次数不减 / 普通消耗品使用不减 / 无限药品 / 自定义药品次数 / 自定义药品持续时间
· 飞行与穿墙：飞天、飞行速度、穿墙移动、安全返回、高度调整。
· 六十六天模式：死亡不扣次数、周目、难度、剩余次数。

  · 分类行两端有 ‹ › 箭头，鼠标滚轮也能横向滚动。
  · 搜索支持多关键词：空格分开、全部命中才显示（例如「反击 护腕」）；也支持松散匹配
    （「反腕」能搜到「反击护腕」），结果按相关度排序，右侧显示「命中数 / 总数」。
· 背包管理：当前背包 551 项，可改持有数量或删除整条记录（删除不可撤销）。
· 生成怪物：177 种敌人，可设数量 1~10、距离、敌/友军；会显示原生生成状态。
  · 「首领」分类会提示：剧情首领带阶段机制，血量见底后可能不再下降（需要过场/阶段推进）。
  · 右侧「开启助战预设」：一键打开 伤害倍率 / 快速破防 / 玩家不被破防 / 自动完美格挡 /
    自动 QTE（不含秒杀）。再点一次即"关闭助战预设"，全部还原。
  · 「还原全部修改」：整体还原本次连接期间做过的可逆修改（攻击系数、速度、外观等）。
  · 还打不动就用「记录当前位置 / 传回记录点」脱战，离开区域后生成的怪会随场景卸载。
  · 仍然注意：「伤害倍率」开着时敌人会掉血很快；觉得太脆就先关掉助战预设再点还原。
· 探索与地图：179 个已解锁地点，选中「前往」直接传送；也可记录当前位置再传回。
· 自定义任务：读取全部任务（80 项）并显示状态，可「标记完成」或「重置任务」；会改变剧情进度。
· 成就：66 项成就，可点亮或取消。
· 外观解锁：9 套服装外观，解锁后到游戏内外观界面切换。
· 角色模型：429 个模型可替换（首领 / NPC / 剧情人物），用完点「还原默认」。
· 技能释放：1500+ 条攻击技能，选中后直接释放一次；被动与配对处决不可单独释放。
· 技能连段：左侧挑招式加入右侧队列（最多 30 步），设好间隔（默认 800ms）点「执行连段」，可随时停止。
· BOSS 招式：播放首领招式；只有在首领战中锁定首领后目录才会有内容，页面会自动重试 3 次。
· 资源设置：107 项养成资源（铸造金属 / 琥珀 / 货币等），输入数量后点「设置数量」。
· 角色属性：223 项属性（等级 / 生命 / 伤害与抗性 / 破防 / 移动等），填绝对值写入，改前先记原值。
· 一键全收集：九类收集 / 所有任务 / BOSS 战绩 / 所有地图探索。
  · 执行前会弹窗二次确认；执行中显示「已检查 x/y · 补齐 a · 仅记录 r · 未完成 f」。
  · 结束后弹结果窗：列出本次补齐了哪些、仅更新了哪些记录、哪些没完成及原因。

【快捷键】
· 「更多 → 快捷键」集中管理：
  · 唤出 / 隐藏修改器：预选 F1~F12、Ctrl+F1/F2、Insert、Home，或点「自定义…」直接按下
    你要的组合键（Esc 取消）。游戏里按一下把修改器叫到最前，再按收起。此热键不受
    「仅在游戏/修改器前台」限制，所以隐藏后仍能唤回。
  · 一键生成怪物：在「生成怪物」页选中怪物、设好数量与距离，再点右侧「选择热键」
    （预选 F5~F12、Ctrl+1~5，同样支持自定义）。之后游戏里按下即生成，不必切回修改器。
    此热键只在游戏或修改器前台时响应，避免在别的程序里误触。
  · 两个热键用了同一组合键时，会弹窗提示冲突。
· 功能卡片上的「设置快捷键」可为任意功能单独绑定全局热键（游戏在前台也生效）。
· Ctrl+F 跳到当前页的搜索框。

【记住上次设置】
底栏有一个「记住上次设置」开关，默认开启：
· 开启时：打开修改器会自动套用上次的开关与数值，连上游戏后直接生效；
· 关闭时：每次启动都是全部关闭的干净状态（存档页签、热键仍会保留）；
· 改完立即生效并写入，下次启动按这个设置来。

【连不上 / 显示未就绪】
· 状态栏会直接显示游戏侧给的原因（例如「当前入口格式尚未适配」「任务系统尚未就绪」），
  不再是笼统的「等待进入场景」。
· 打开「更多 → 连接诊断」→「开始诊断」，会列出：程序版本、是否管理员、检测到的 PBZ 进程、
  ready / catalogReady / 场景 / 角色 / 坐标，以及 12 个目录的读取结果。
  点「复制」或「保存到桌面」，把文本发给作者即可定位问题。
· 连接失败时，窗口底部提示条会把原因和排查建议一起显示（约 6 秒）；
  连不上先看这一条，通常是游戏装了 mod。

【数据与存档】
· 开关、数值、页签、热键自动保存：%LOCALAPPDATA%\影之刃零修改器\trainer_state.json
  （字段：SelectedPage / AutoSave / OnlyWhenTargetOrPanelForeground / PanelToggleHotkey /
    RestoreSettings / SpawnHotkey / SpawnHotkeyId / SpawnHotkeyName / SpawnHotkeyCount /
    SpawnHotkeyDistance / SpawnHotkeyFriendly / Features{Enabled,Value,Hotkey}）
· 添加物品、改数量、删除、全收集、任务、成就、属性都会真实写入存档，关掉修改器不会撤销，
  请先备份。

【常见问题】
· 弹窗「运行环境未就绪」：程序自带的运行模块没写进磁盘，多被杀毒软件拦了。
  按弹窗里的三步做（把程序文件夹和 %LOCALAPPDATA%\影之刃零修改器 加入白名单 → 重开）。
  程序会自动在三个位置尝试，通常加完白名单重启就好，不需要你找任何文件。
· 「请先启动游戏」：游戏没开或还没读到进程，开游戏后自动重连（每 6 秒重试）。
· 「游戏接口尚未就绪」：游戏刚启动，等几秒再点「重新连接」。
· 「游戏版本与本程序不匹配」：当前包和你的游戏不是同一版，需要换对应版本的程序，改参数没用。
· 「连接被占用」：已有另一个修改器窗口连着，或上次异常退出留下会话。先关掉其他窗口；
  仍不行就完全退出游戏再重开一次。
· 连接失败（注入失败、接口没就绪、版本不匹配）：先确认游戏有没有装 mod——mod 会改游戏文件或内存，
  容易被当成版本不匹配。把 mod 关掉、完全退出游戏再重开，然后点「重新连接」。
· 「已开启 · 未生效」：见上文【卡片状态怎么读】，属于游戏版本未适配。
· 小地图/透视开启失败并提示「正在读取游戏目录」：游戏还在加载，等几秒再开。
· 透视显示「视野内暂无目标」：当前画面里没有符合勾选类型的目标（把类型全勾上试试）。
· 按了唤出热键没反应：确认该组合键没被其他软件占用；可以在「更多 → 快捷键」里换一个。

【卸载】
删除本目录，再删除 %LOCALAPPDATA%\影之刃零修改器 即可；不写注册表、不留服务。

【技术备注】
· 功能清单取自原版模块内嵌资源 PBZFeatures.json（76 条）与 PBZCatalog.json
  （items 790 / enemies 177 / achievements 66 / quests 80 / collections 630 / resources 99）。
· 协议：命名管道 \\.\pipe\ChuwuPBZ_v1_<游戏PID>，帧 = 4 字节小端长度 + UTF-8 JSON；
  每个请求自动附加 requestId / session / clientPid。
  指令：hello、capabilities、feature、collection_step、catalog{type}、grant_items、
  inventory_change、spawn/spawn_status、revive_enemy、position、teleport、
  collection_locate、completion.plan/begin/step/cancel、minimap.configure/frame/
  travel_target、esp.configure/frame/status 等（job / value 等字段须按原类型传，数字就是数字）。
