影之刃零 修改器 v1.11.15 · 首次使用
================================================

【三步用起来】
1. 先启动游戏（影之刃零 / Phantom Blade Zero），进入存档、角色能自由行动。
2. 双击 PBZTrainer.exe。会弹一次 UAC（管理员权限），点「是」。
   · 程序默认要管理员权限：这样游戏无论普通还是管理员启动，都能连上。
   · 不弹 UAC / 点了「否」的话，可能读不到游戏进程。
3. 右上角变成「● 游戏已就绪」就能用了；如果显示「请先启动游戏」，
   把游戏开起来，它每 6 秒会自动重连，不用管。

【界面长什么样】
左边是分组导航（点分组标题能展开/收起），右边是当前页：
  功能   —— 10 个分类，76 项开关，拨一下即时生效
  物品   —— 添加物品 / 背包管理
  世界   —— 生成怪物 / 探索与地图 / 小地图 / 透视
  更多   —— 任务 / 成就 / 外观 / 角色模型 / 技能 / 连段 / BOSS 招式 / 资源 /
            属性 / 快捷键 / 连接诊断
  自动化 —— 一键全收集
功能页顶部有搜索框（Ctrl+F）；工具页分类行两端有 ‹ ›，滚轮也能横向滚。

【先学会看状态】
卡片右下角那行字很关键：
  「已关闭」            —— 没开
  「已开启」            —— 已生效
  「已开启 · 未生效」橙字 —— 开关开了但游戏没响应（当前游戏版本没适配）
悬停在卡片上能看到具体原因。橙字的功能不用反复试，换别的办法更省时间。

【两个热键，很省事】
打开「更多 → 快捷键」：
· 唤出 / 隐藏修改器：默认 F1。点「选择热键」可以换成 F1~F12、Ctrl+F1/F2、Insert、Home，
  或者点「自定义…」直接按下你想要的组合键。在游戏里按一下就能把修改器叫到最前。
· 一键生成怪物：在「生成怪物」页选中怪物、设好数量距离，再点右侧「选择热键」。
  之后在游戏里按下就生成，不用切回来点。

【常遇到的问题】
· 杀毒软件报毒 / 文件被删
  它要和游戏进程交互，行为像木马，容易被误报。把 exe 所在文件夹加入杀软白名单
  （或 Windows 安全中心 → 病毒和威胁防护 → 排除项）。被隔离就先从隔离区恢复。

· 提示「游戏版本与本程序不匹配」
  这个包和你的游戏不是同一版，换对应版本的程序；改设置没用。

· 提示「连接被占用」
  已经有一个修改器窗口连着，或上次异常退出留了会话。关掉其他窗口；
  还不行就完全退出游戏（不是最小化）再重开一次。

· 提示「访问游戏进程失败 / 请保持相同运行权限」
  用管理员身份重新运行修改器（右键 →「以管理员身份运行」）。

· 小地图 / 透视开了没反应
  它们浮在游戏画面上：小地图在右上角，透视是目标框和「名称 + 距离」。
  提示「正在读取游戏目录」就等几秒再开；修改器窗口在前台时悬浮层会自动隐藏。
  透视显示「视野内暂无目标」= 当前画面没有你勾选的类型，把类型全勾上试试。

· 消耗类功能（药剂不减、消耗品不减）开了没效果
  这几项在当前游戏版本里游戏侧回报"已应用"但实际数量不变，所以卡片会显示
  「已开启 · 未生效」。属于版本没适配，不是操作问题。

· 完美闪避躲不掉红光
  当前只触发普通闪避，红光等"不可闪避"攻击仍会命中。可以配合「闪避无敌窗口」用。

· 按了唤出热键没反应
  可能被别的软件占了同一个组合键，去「更多 → 快捷键」换一个。

【务必注意】
· 会写存档的功能：添加物品、改数量、删除、一键全收集、任务、成就、属性。
  关掉修改器不会撤销，动手前先备份存档，一般在：
  %USERPROFILE%\AppData\Local\PBZ\Saved\SaveGames
  （不同版本可能不同，按你游戏实际目录找）
· 只适用于单机，别带去联机 / 排行榜之类的场景。
· 自己留着用就行，别再往外传播。
