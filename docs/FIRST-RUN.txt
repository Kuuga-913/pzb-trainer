影之刃零 修改器 · 首次使用（先看这个）
================================================

【三步用起来】
1. 下载 PBZTrainer-v1.0.1-win-x64.exe（单文件，免安装，自带运行时）。
2. 先启动游戏（影之刃零 / Phantom Blade Zero），进入存档、能自由行动。
3. 双击 PBZTrainer.exe。右上角变成「● 游戏已就绪」就可以用了；
   如果显示「请先启动游戏」，把游戏开起来，它会每 6 秒自动重连。

【这个工具是什么】
影之刃零的单机修改器：左侧是分类（战斗与生存、异常与持续伤害、杀气与绝技、速度与冷却、
破防与处决、格挡与鬼步、资源与消耗、飞行与穿墙、六十六天模式、地图与收集），右边是功能卡片，
拨开关即时生效。
另有 添加物品 / 背包管理 / 生成怪物 / 探索与地图 / 小地图 / 透视 / 一键全收集 等工具。

【常见问题】
· 杀毒软件报毒 / 文件被删
  它需要和游戏进程交互，行为和木马类似，所以容易被误报。
  把 exe 所在文件夹加入杀软白名单（或 Windows 安全中心的「排除项」），
  如果文件被隔离，先从隔离区恢复再重新下载一次。

· 提示「游戏版本与本程序不匹配」
  说明你的游戏版本和这个程序不是同一版（程序与游戏版本是一一对应的）。
  这种情况需要用与你游戏版本对应的版本，改参数没用。

· 提示「访问游戏进程失败 / 请保持相同运行权限」
  如果游戏是用管理员身份启动的，修改器也要右键 →「以管理员身份运行」。

· 提示「游戏接口尚未就绪」
  游戏刚启动，等几秒再点「重新连接」。

· 小地图 / 透视开了但没反应
  它们会浮在游戏画面上：小地图在右上角，透视是目标框和「名称+距离」标签。
  点开时如果提示「正在读取游戏目录」，等几秒再开；修改器窗口在前台时悬浮层会自动隐藏。

· 透视显示「视野内暂无目标」
  当前画面里没有符合勾选类型的目标，把类型全勾上再试。

【务必注意】
· 会写存档的功能（添加物品、改数量、删除、一键全收集）关掉修改器不会撤销，用之前先备份存档。
  存档位置一般在：
  %USERPROFILE%\AppData\Local\PBZ\Saved\SaveGames
  （不同版本可能不同，按你游戏实际目录找）
· 只适用于单机。别带去联机 / 排行榜之类的场景。
· 自己留着用就行，别再往外传播。
