影之刃零修改器 · 首次使用（先看这个）
================================================
游戏版本要一致。PBZBridge.dll 是跟着游戏版本走的（内部 buildId 是 pbz-eabf89dea2775ae4eab0f75a）。如果游戏版本不同，连上会提示「游戏中的组件版本不同」，这个改配置解决不了，得换成对应版本的组件。
权限对齐。如果他是用管理员身份开游戏，修改器也要右键「以管理员身份运行」，否则会提示访问游戏进程失败。
【三步用起来】
1. 把整个压缩包解压到任意目录（不要在压缩包里直接双击）。
   注意：PBZTrainer.exe 和 PBZBridge.dll 必须在同一个文件夹里，缺一个都用不了。
2. 先启动游戏（影之刃零 / Phantom Blade Zero），进入存档、能自由行动。
3. 双击 PBZTrainer.exe。右上角变成「● 游戏已就绪」就可以用了；
   如果显示「请先启动游戏」，把游戏开起来，它会每 6 秒自动重连。

【这个工具是什么】
影之刃零的单机修改器：左侧是分类（战斗、杀气、速度、破防、异常、格挡、资源、飞行、
六十六天、地图收集），右边是功能卡片，拨开关即时生效。
另有 添加物品 / 背包管理 / 生成怪物 / 探索与地图 / 小地图 / 透视 / 一键全收集。

【常见问题】
· 杀毒软件报毒 / 文件被删
  它会把组件注入游戏进程，行为和木马类似，所以容易被误报。
  把整个文件夹加入杀软白名单（或 Windows 安全中心的"排除项"），
  如果 PBZBridge.dll 已经被隔离，先从隔离区恢复，再重新解压一次。

· 提示「游戏中的组件版本不同，请重启游戏后再连接」
  说明你的游戏版本和附带的 PBZBridge.dll 不匹配（组件是跟着游戏版本走的）。
  这种情况只能换成与你游戏版本对应的组件，或者等更新，改参数没用。

· 提示「访问游戏进程失败 / 请保持相同运行权限」
  如果游戏是用管理员身份启动的，修改器也要右键 →「以管理员身份运行」。

· 提示「游戏仍加载着旧组件…」
  游戏里已经有一份旧组件了。完全退出游戏（不是切回桌面）再重新开。

· 小地图 / 透视开了但没反应
  它们会浮在游戏画面上：小地图在右上角，透视是目标框和「名称+距离」标签。
  点开时如果提示「正在读取游戏目录」，等几秒再开；修改器窗口在前台时悬浮层会自动隐藏。

【务必注意】
· 会写存档的功能（添加物品、改数量、删除、一键全收集）关掉修改器不会撤销，用之前先备份存档。
  存档位置一般在：
  %USERPROFILE%\AppData\Local\PBZ\Saved\SaveGames
  （不同版本可能不同，按你游戏实际目录找）
· 只适用于单机。别带去联机 / 排行榜之类的场景。
· 自己留着用就行，别再往外传播。
